# داشبورد شخصی — نسخه ۲

نسخه دوم داشبورد شخصی، بازنویسی‌شده با Flutter.

## وضعیت فعلی

- رابط فارسی و RTL
- تم روشن و تاریک
- طراحی Liquid Glass
- مدیریت تسک‌ها
- مدیریت درآمد و هزینه
- مدیریت بدهی و اقساط
- ذخیره‌سازی محلی با Drift/SQLite
- محاسبات مالی دقیق
- پشتیبانی از Android، Linux، Windows و macOS
- بدون پشتیبانی iOS

## توسعه

```bash
flutter pub get
dart run build_runner build --delete-conflicting-outputs
flutter analyze
flutter test
flutter run
```
